长版研究纪要

受访者与机构角色
  • 受访者处在巴黎目的地推广 / 旅游办公室体系内，视角不是单一商业供应商，而是兼具城市推广、会员服务、票务分销、目的地管理的公共 / 准公共机构视角。
  • 她多次区分「自己能回答的领域」和「商务 / 票务部门能回答的领域」，说明机构内部有清晰分工：推广、数据、传播、票务、商业合作并不完全由同一人负责。
  • 机构与巴黎市政府 / 城市管理方有关系，推广策略不只看销售转化，也服务城市层面的游客流量分布、街区形象与公共利益。
  • 对外沟通中，机构强调「官方 / 机构性声音」的责任，不能像普通平台一样只追热点；内容发布需要在经典巴黎与小众巴黎之间保持平衡。
  • 对中国平台而言，这类机构不是简单供应商，而更像目的地入口、资源协调者、票务节点和城市政策方向的解释者。
统计观察平台与会员数据服务
  • 机构向会员提供统计观察服务，用于查看旅游数据、年度走势、未来客流预期，以及哪些时期可能更困难。
  • 数据服务是会员权益的一部分，说明该机构不只是面向游客，也面向巴黎旅游生态中的酒店、景点、服务商等从业者。
  • 受访者提到会把去年的关键数字发给采访方，并在拿到新数字后继续发送，显示其数据更新可能有年度节奏。
  • 对中国市场，她提到「中国大幅下降」，但没有在访谈中给出可引用的精确数字；报告中应避免自行补充比例或年份。
  • 采访中出现 commissariat pour le transport 相关表述，但正式机构名仍需回听确认，不宜当作确定的官方部门名称。
RATP 票务与经销商位置
  • 机构销售 RATP 的交通票、通票，以及旅游参观类票务；但她明确表示不销售酒店间夜。
  • 受访者称他们是 RATP 的重要经销商，尤其在历史上承担较大销售量；但也强调并非 RATP 唯一经销商。
  • 普通游客不一定需要通过该机构买票，也可以直接在地铁站购买；机构价值更多体现在提前购买、团体购买、大批量购买和组织化票务。
  • 对于提前购买或人数很多的需求，RATP 会把客户引导到他们这里，这使其成为 MICE、团队游、学校团、企业团等场景的关键节点。
  • 这类交通票务关系对中国平台很重要：若只做散客即时票，优势有限；若做团体、预售、套餐、B2B 分销，则更接近该机构的核心业务。
团体票、大批量票与套餐化机会
  • 受访者明确把团体票 / 大批量票务视为主要业务之一，这与采访方提出的中国游客套餐、法国本地游客套餐、MICE 需求高度相关。
  • 交通票可以成为巴黎产品包的基础组件：机场 / 市内交通、地铁通票、景点门票、城市游览可以组合成更适合外来游客理解的产品。
  • 对中国游客而言，提前整合票务能降低现场购票、语言沟通、排队和规则理解成本，尤其适合第一次来巴黎或跟团 / 半自助客群。
  • 但受访者没有给出票务佣金范围，也没有确认不同供应商的返点结构；佣金、合同和商业条款必须由负责票务的 Thomas 或商务团队确认。
  • 因此，报告应把「团体 / 批量」作为平台切入点，而不是泛泛讨论「卖巴黎门票」。
OTA、平台与 Kombo 关系
  • 采访方提到 SNCF、Kombo 和本地交通公司，显示其关注的是法国交通供应链，而不只是目的地景点。
  • Kombo 被介绍为法国交通预订平台，采访方称其位于圣旺、整合大量交通伙伴；受访者一开始不熟悉，后确认理解为 Kombo。
  • 受访者表示机构似乎没有与 Kombo 合作，并补充会再核实；因此不能把 Kombo 写成既有合作伙伴。
  • 她承认 OTA / 平台关系不是自己的专业领域，回答时多次谨慎，说明这部分信息应作为「受访者个人了解范围内的判断」处理。
  • 对中国平台而言，Kombo 这类交通聚合商代表另一类竞争 / 合作对象：它们解决跨运营商交通预订，而旅游办公室更偏目的地官方入口与票务分销。
Thomas 与票务商务交接
  • 受访者明确提出可把采访方转给 Thomas，因为 Thomas 负责整个票务相关事务。
  • 商业合作、佣金区间、供应商合同、具体票务产品接入等问题，受访者都没有强行回答，而是建议由 Thomas 处理。
  • Thomas 不常在办公室，更多远程办公，因此后续沟通可能以视频会议为主。
  • 这说明后续推进应准备非常具体的 B2B 票务合作清单：希望接哪些票、目标客群、销售方式、预计批量场景、是否需要 API / 白标 / 分销协议。
  • 页面应把 Thomas handoff 写成「商业可行性尚未完成验证」，不要把受访者的初步认可误写成已进入合作谈判。
中国 B2B、Trip.com 与竞合关系
  • 受访者认同目前与中国旅行社或大型中国平台的直接关系似乎不多，但对具体合作名单并不完全确定。
  • 问到 Trip.com 时，她表示当然知道这个平台，但不确定是否有既有合作关系，需要 Thomas 确认。
  • 她对 Trip.com 的判断很关键：一方面双方有竞争，因为机构自己也卖门票和参观产品；另一方面机构也可能作为供应商存在，因此关系是「既竞争又有业务关系」。
  • 她认为中国平台 / 旅行社之所以更容易服务中国游客，是因为它们了解客户期待、会中文，并且已有中文导游等生态。
  • 机构通常在困难情况中被请求协助，例如某些时期酒店全满、需要寻找解决方案；这说明官方机构更像兜底协调者，而不是日常中国游客服务的唯一入口。
酒店供给、连锁与独立酒店
  • 采访方提到巴黎酒店从一星到五星、不同档次供给；受访者补充四星 / 五星并不总是连锁酒店，巴黎仍有很多独立酒店。
  • 访谈中提到法国超过 60% 酒店为独立酒店，这一数字来自对话背景并得到受访者认可，但报告中仍应表述为「访谈中提及 / 对方认可」，不要扩展为未经核验的市场统计。
  • 与独立酒店合作并非不可能，受访者强调没有特别障碍；真正问题是耗时，因为需要逐家沟通。
  • Accor 被视为非常重要的大型合作伙伴之一，但不是唯一；IHG、Louvre Hotels 也被提及为其他大型酒店业参与者。
  • 对中国平台而言，大集团适合快速建立标准化合作，独立酒店更适合做差异化库存、精品住宿、本地街区体验，但获客和签约成本更高。
AI 使用与服务商数字化
  • 采访方重点询问旅游服务供应商是否越来越接受 AI；受访者认为 AI 已经存在于各类平台中，很多时候用户未必直接看见。
  • 她认为 AI 能简化工作、提升效率，巴黎服务商也在使用 AI。
  • 但她也指出行业态度分化：有人害怕 AI，有人很高兴获得快速高效的工具。
  • 机构自身「有意」还没有大量使用 AI，并有团队在研究相关产品；这体现出公共 / 官方机构对 AI 的采纳更谨慎。
  • 对中国平台的启示是：AI 不宜只包装成炫技功能，更应落在多语种内容、产品匹配、客服、团队票务管理、分流推荐、供应商后台自动化等实际效率场景。
客户文化差异与首次访客必看景点
  • 受访者认为不同国家游客的行为和期待差异很大；法国人与比利时、瑞士等法语 / 欧洲近邻客群更接近，但与卡塔尔等远程客群差异很大。
  • 她强调巴黎具有极强目的地吸引力：埃菲尔铁塔的图像全球皆知，很多人天然想去巴黎和看经典地标。
  • 对第一次到巴黎的游客而言，《蒙娜丽莎》、埃菲尔铁塔、圣心大教堂等经典项目几乎是必须完成的行程。
  • 旅游办公室虽然希望推广其他巴黎，但也承认首次访客通常不会听从「避开经典景点」的建议，因为他们花了机票和酒店钱，想看自己长期期待的巴黎。
  • 复游客才更可能接受购物、陌生街区、更巴黎人、更真实或更小众的体验；产品设计必须区分首次访客与复游客。
过度旅游、热点压力与巴黎的判断
  • 受访者明确表示，巴黎整体并不处于过度旅游状态。
  • 她对过度旅游的定义接近居民强烈排斥游客，例如出现 tourists go home 式标语；她把巴塞罗那、威尼斯作为更典型例子。
  • 巴黎确有局部紧张区域，如蒙马特高地、玛黑区，以及埃菲尔铁塔、卢浮宫、歌剧院、香榭丽舍等高游客密度区域。
  • 她也提到某些街区居民减少、功能变化，这说明问题不是简单的游客数量，而是居住、商业、流量和城市生活之间的结构性变化。
  • 因此应避免把巴黎描述成「严重过度旅游城市」，更准确的表述是「整体未达到过度旅游状态，但头部景点和部分街区存在高压与分流需求」。
分流策略、另类街区与具体地点
  • 机构会把精力和预算投向更需要推广的区域，而不是继续推广全年客满的埃菲尔铁塔或卢浮宫。
  • 受访者提到第 5、11、17 区等可被发展，也讨论第 10、18、19、20 区等相对不那么主流或形象更复杂的区域。
  • 拉德芳斯的新沉浸式活动被用作例子：不在市中心，但对熟悉巴黎、想看新东西的游客可能有吸引力。
  • 圣旺周末的 marché aux Puces 被描述为世界级跳蚤市场场景；她强调周末有吸引力，其他时间不一定危险，但可能没有太多可看。
  • 对危险感的讨论要谨慎：受访者并不认为这些地方真的危险，而是承认存在公众印象问题；推广时需要同时解决目的地形象、到访时间、交通动线和内容叙事。
社交媒体、影响者与微信渠道
  • 机构有小型社交媒体团队，并与代理机构合作；代理机构是付费合作，但影响者通常不付费，因为预算有限。
  • 他们合作的影响者往往居住在巴黎、面向外国受众，例如在巴黎生活的墨西哥人用西语面向墨西哥受众讲巴黎。
  • 受访者提到美国、英国、日本、中国等面向不同海外受众的影响者，说明其海外传播不是单一英语逻辑。
  • 机构内部有一位中国背景人员专门负责微信，这说明中国渠道已被纳入官方传播体系，而不是完全依赖外部平台。
  • 对中国平台而言，微信 / 小红书 / 抖音式内容可以与官方社媒形成互补：官方适合可信背书，平台适合交易转化、攻略包装和用户运营。
票务外包、佣金与中国平台启示
  • 票务管理近期发生变化：受访者称从上周起不再由机构自己直接管理全部票务，而是委托一家私营公司运营。
  • 该公司名称在转写中为 Mon Petit Paris，但校准说明提示可能需要回听确认是否为 My Little Paris；正式引用时不应过度确定。
  • 该承包 / 特许经营方负责网站更新等大量运营工作，并向机构返还佣金；这说明机构已把部分复杂运营外包，以释放内部团队时间。
  • 对中国平台来说，合作对象可能不止旅游办公室本身，还包括其票务承包商、RATP 经销链条、景点 / 活动供应商和社媒代理网络。
  • ASR caveats：MICE、Mon Petit Paris / My Little Paris、commissariat pour le transport、酒店独立 / 连锁重叠发言段，以及少数无法复原片段都应标记为需回听确认，不能作为强结论引用。
