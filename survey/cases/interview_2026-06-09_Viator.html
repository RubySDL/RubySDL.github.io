长版研究纪要

受访者角色与访谈背景
  • 受访者 Alexey 是 Viator 内部人士，常驻英国（非巴黎）；访谈开场曾被问能否用中文进行，他澄清自己不会中文，全程英语。
  • 采访方为中国平台的市场调研人员，围绕 Viator 在法国 tours & activities（旅游产品与活动）市场的业务展开提问。
  • 受访者反复强调因仍在与 Viator 的合约期内，不会分享任何确切的公司数字；因此关于规模、客单价、佣金等多以量级或区间作答。
  • 访谈先就 business coverage（业务覆盖）的口径做了澄清——指平台上可售产品与供应商的供给规模。
Viator 业务模式与供给覆盖
  • Viator 是一个全球性 marketplace（市场平台），对接全球众多合作伙伴；tours & activities 是高度碎片化、品类繁多的市场。
  • 覆盖品类包括徒步游、门票、博物馆、景点、体验、美食游、文化游、机场接送等，尽量在包括法国在内的所有运营地区做全覆盖。
  • 法国的供给天然集中于景点类（巴黎圣母院、埃菲尔铁塔等围绕地标的体验最突出、最高频），但平台策略并非偏重某一细分，而是尽可能多覆盖。
  • 受访者称 Viator 拥有全球最大的供给量，这是其相对最接近的竞争对手 GetYourGuide 的核心优势——供给的广度与深度。
法国市场的战略定位
  • Viator 以「全球优先」做战略思考，但法国是最重要的目的地之一，App 已做法语本地化与翻译。
  • 法国市场的大部分投入集中在营销侧：数字营销、SEO、捕获流向该市场的流量；并有专门团队对接法国本地供应商。
  • 产品侧的偏好是构建对所有客户/供应商通用的全球化能力，而非针对法国、德国或某一地专门开发。
  • 受访者明确：产品战略不会依赖法国，整体战略围绕「让旅客构成多元化」。
用户地理分布与画像
  • Viator 隶属 TripAdvisor 集团，旅客以美国为主；按国籍看，绝大多数是讲英语的美国人和英国人，占流量最大份额。
  • 法国本地（境内游）旅客占比很小——法国人更多是在出国（去意大利、德国等）时才高频使用，法国人在法国境内做短途游较为少见。
  • 典型用户画像：来自美国或英国、两位大人带一个孩子的家庭，赴法度一周假；这一「家庭/情侣」结构是全球性趋势，不分国籍。
  • 预订行为：多在出发前几天，或已抵达目的地后才寻找体验（到了巴黎再想「玩什么」）。
用户规模与流量来源
  • 用户规模为数百万级别（受访者只能给到量级，称连确切数字自己也无法获得，因需汇总所有合作伙伴的数据）。
  • 流量来源多元：TripAdvisor App 中的「体验」即来自 Viator；Viator 还有公开 API，被 Expedia、Booking.com 等大玩家接入，由此带来大量旅客。
  • 因此 Viator 自身只能看到经由 TripAdvisor、Expedia 等渠道来的部分旅客，无法看到全貌。
  • 日活（DAU）等更细数据受访者当场无权限/无法提供。
客单价、提前期与取消率
  • 客单价：受访者不报公司数字，但提示官网上多数活动定价约 40–50 英镑/活动/人，结合「两大一小家庭」可自行估算。
  • 预订提前期：多为出发前几天，或已在目的地后下单。
  • 取消率不高：平台对供应商主动取消很严格，设有阈值与罚则（超额取消会被判定低质、影响展示权重）；而旅客可在很短通知期内免费取消/改期，这被视为产品优势。
体验品类偏好（法国）
  • 毫无疑问的赢家是景点类：埃菲尔铁塔、巴黎圣母院、卢浮宫、凡尔赛宫等的导览游、团队游、徒步游。
  • 其次是泛城市徒步游（看建筑、感受文化），再次是美食与葡萄酒游。
  • 高端市场存在私人游（如出城到酒庄、葡萄酒生产商的私人行程），面向有能力支付更高价格的旅客；法国并非只服务大众低价客群。
增长趋势与宏观判断
  • 全球与法国的 tourism activities 大致两位数增长（约 10–20%，也可能 20–30%），GetYourGuide 同样两位数增长。
  • 受访者用「飞往法国的航班与售出座位数」作为增长代理指标；当前更多欧洲人在欧洲内部旅行、美国人赴欧，亚洲赴欧因冲突与机票上涨而减少。
  • 他判断一旦东欧、中东等全球性扰动结束，亚洲客流回归将带来更大增长。
佣金结构（managed vs unmanaged）
  • 基础佣金率约 20%，起始区间 20–25%，但实际可在 5%–60% 之间，取决于具体供应商及客户经理的商业决策。
  • 提供「以更高佣金换更多曝光」的产品；大供应商也可能拿到更低佣金却保留全部权益。
  • 区分托管（managed，大供应商，有客户经理、大量谈判）与非托管（unmanaged，太小、自助签标准合约上架）；非托管的标准费率约 21–22%，想要更多曝光可上调。
获客渠道与 AI 新渠道
  • 主要渠道：TripAdvisor 导流、供合作伙伴接入的公开 API、以及搜索引擎（Google、Bing、Yahoo）的 SEO。
  • 来自搜索引擎的旅客占比正在下降——Google 的更新让答案直接呈现在搜索结果中，用户无需点开网站，冲击全行业流量。
  • 应对：① 提升品牌认知与既有用户留存，减少流失；② 把 AI 智能体/AI 搜索作为新渠道，确保其组织答案时能调用 Viator/TripAdvisor 的 API。
  • 受访者提到 Viator 已与 Anthropic 完成集成（疑为购物类功能 shopping action），与大型 AI 公司合作让 API 成为新渠道。
竞争格局
  • 最主要竞争对手是 GetYourGuide，量级上无人能及；Google 的 things to do 不算真正对手，服务场景不同。
  • Klook 是更小的竞争者且更活跃于亚洲，而 Viator 聚焦欧洲。
  • Tiqets 近期被 Expedia 收购：Expedia 既是 Viator 的 API 合作伙伴、又新拥有内部供货公司，且 Tiqets 专注博物馆/景点门票——这恰是法国的关键品类，受访者对此略有担忧。
  • Civitatis 在受访者看到的统计中均未显示为大玩家。
优势、劣势与核心挑战
  • 优势：供给的广度与深度（可售产品数量、已激活供应商数量更多）。
  • 劣势：GetYourGuide 在捕获欧洲旅客上做得很好——分工大致是「Viator 把美国人带到欧洲，GetYourGuide 让欧洲人探索欧洲」，源于 Viator 历史上高度依赖在美国更知名的 TripAdvisor 品牌。
  • 核心挑战：对美国旅客的依赖；长途国际旅行更易受通胀、冲突、燃油成本等扰动影响。缓解方向是让旅客来源多元化、吸引更多欧洲/法国及新地区旅客。
  • 其余如折扣管理、供应商与产品排序等被视为更小、可优先级排期解决的问题。
法国本地化运营
  • 托管供应商可获法语支持：destination managers（类似客户经理/商务经理）几乎都是法语母语者，负责本地市场对接。
  • 非托管供应商直接联系默认讲英语的客服团队，但借助自动翻译可用法语往来沟通，本地化已不太成问题；旅客端平台已翻译为法语。
  • 是否有专门的法语客服，受访者坦言不确定，会去核实。
  • 支付：支持各类银行卡（Visa、MasterCard、American Express），Apple Pay 可能支持（需核实），不支持 chèque vacances；平台一大差异化功能是「延迟付款」——预订可免费保留至活动开始前 24 小时才扣款，深受旅客欢迎、运营商则更想立即收款（平台「旅客优先」）。
行业长期趋势
  • 数字化：越来越多运营商转向预订系统与渠道管理工具，依赖 API 与第三方平台分发；对 Viator 是利好（用一个 API 替代对接上万家运营商）。
  • 但市场仍极碎片化：很多优质产品由「巴黎一个人做徒步游」式的小供应商提供，常用 Excel 管理、无 API、偏好直接在 Viator/GetYourGuide 上自建并手动维护产品。
  • 动态定价：定价难是行业痛点，动态定价引擎（参考竞品活动、自身可售情况、甚至天气）正变得普遍，行业将更像航空业的动态定价，取代当前大量手动维护的月度价格表。
对中国平台（trip.com）的建议
  • 建议一：与本地平台/预订系统合作，而非自建——tours & activities 高度碎片化，自行进入需手动收集 50%–60% 的内容，基础设施复杂、风险高；不如接入 GetYourGuide 或其他已有 API 的系统。
  • 建议二：先想清楚要服务谁——「法国供给」与「法国用户」是两套完全不同的战略与行为模式。
  • 受访者假设 trip.com 想要的是供给（把法国活动卖给中国客人）；若改为要获取法国本地客户，则战略重心从供给获取转向用户获取。
成本结构
  • 受访者无法给出确切的员工/运营成本百分比；强调成本更多来自基础设施而非单纯人力。
  • 由于非托管供应商需在平台内手动创建价格、排期与内容，Viator 必须自建并维护这套流程（航空/酒店只需接 API 消费价格与排期，无需自建）。
  • 这需要多个工程团队（工程师、产品经理、设计师）加部分客服支持来构建能力；但排期本身由供应商维护，Viator 只提供工具。
