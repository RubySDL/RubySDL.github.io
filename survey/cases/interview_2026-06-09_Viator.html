详细访谈记录（按主题）

受访者画像与访谈背景
  • 受访者 Alexey 为 Viator 内部人士，常驻英国（开场被问是否常驻巴黎，他明确否认）；被误以为会中文，实际不会，访谈用英文进行。
  • 他与采访方同事事先约定：因仍在 Viator 合约期内，不会分享任何确切公司数字（供给数量、用户数、客单价、增速、佣金等均只给区间或定性），多次强调「分享具体数字会违反合约」。
  • 采访方为中国平台调研团队，问题高度结构化，覆盖业务覆盖、战略地位、用户画像、财务模型、佣金、获客、竞争、本地化、支付、成本与对中国平台的建议。
  • 对自己没有权限或没把握的数据（如 DAU、是否有专属法语客服、是否支持 Apple Pay/本地支付）他坦诚表示「不知道/需要核实」，并多次区分「我的假设」与「有数据支撑的结论」。
Viator 定位：全球 marketplace 与法国供给覆盖
  • Viator 是全球性平台、是一个 marketplace，与全球各地众多合作伙伴合作；tours & activities 是一个非常碎片化、供应商品类繁多的市场，Viator 的策略是「尽量把它们都覆盖到」。
  • 覆盖品类包括徒步游、门票、博物馆、景点、体验、美食游、文化游，甚至机场接送——「所有你能想到的旅游产品和活动品类」，并在包括法国在内的所有运营地区尽量覆盖。
  • 具体到法国，供给非常集中于景点类：巴黎圣母院、埃菲尔铁塔等景点周边的体验更突出、更高频；但 Viator 并非只专注法国供给的某个特定部分，规划策略就是「尽可能多覆盖」。
  • 他援引「公开可得的数据」称 Viator 目前拥有全球最大的供给量；最接近的竞争对手 GetYourGuide 各有优势，而 Viator 的强项正是「供给以及对供给的覆盖度」。
法国在全球布局中的战略地位
  • 作为全球 marketplace，Viator 必须从全球扩张角度做战略思考，而非盯着单一市场；但法国在其定位与打法中确实占据重要位置。
  • 法国被定位为「最重要的目的地之一」：Viator App 做了法语本地化与翻译、支持法语；在数字营销/SEO 上努力捕获流向法国市场的流量，且投入了大量营销活动。
  • Viator 设有专门团队对接法国本地的法国供应商；但每当制定产品策略时，偏好构建「对所有客户/供应商都有用、不分地区」的全球化能力，而非专门针对法国、德国或北京的能力。
  • 结论：法国市场上 Viator 的活动大多与营销相关；产品层面则坚持全球化能力优先。
用户地理分布：以美/英为主
  • Viator 隶属 TripAdvisor 集团，因此大多数旅客来自美国，美国客群占很大比例。
  • 欧洲旅客中，法国旅客占比「老实说不会很大」——因为问的是法国人在法国境内（本地/国内）旅行，而对 Viator 而言占比最大的是国际旅客。
  • 即便是来自法国的旅客，最可能也是英国人、西班牙人、意大利人或德国人，而非法国人自己；法国人真正最频繁使用 Viator，是在出国时（如去意大利、德国），而法国人在法国境内做一日游/短途游「比较少见」。
  • 按比例来看，平台上更常见的是国际旅行而非法国本地旅行。
用户规模与数据口径
  • 用户规模为「数百万级别」，他明确表示不会到两位数（千万级），但平台增长得相当不错；这是他能给出的全部口径。
  • Viator 并非旅客唯一入口：打开 TripAdvisor App 看到的「体验」即来自 Viator；Viator 还有公开 API，被 Expedia、Booking.com 等市场大玩家接入，大量旅客从这些平台导入。
  • 正因为旅客来自多个合作伙伴渠道，他「连确切数字都不知道」——要拿到完整图景需要汇总所有合作伙伴的数据，而其中有些数据他甚至没有权限查看（如通过 TripAdvisor/Expedia 来的旅客量）。
  • 关于日活（DAU），他表示当前没有访问权限、无法马上找到。
典型用户画像与使用场景
  • 最常见的使用人群是家庭，其次是情侣/夫妻，或带孩子的夫妻——这是平台用户中占比最大的群体。
  • 标准用户画像：来自美国或英国、一对夫妻带一个孩子、去法国度一周假；通常在「目的地现场」或「出发前几天」才开始找体验。
  • 典型行为：一家人带孩子，在飞往巴黎前两三天、或已经落地之后，才开始找「有什么可以玩的」。
  • 他认为这是个全球性趋势、不分国籍；并未在法国用户与其他国籍用户之间看到很大差异。
  • （声明为「假设、无数据支撑」）独自旅行者倾向于自己徒步把一切探索一遍；而家庭尤其带小孩时规划更复杂、需要提前安排好能做什么、孩子能否参加。
  • 他观察 GetYourGuide 产品后也「有一种感觉」，其多数客户同样是家庭（带不带孩子）与情侣/夫妻。
预订提前期与客单价（AOV）
  • 平均预订提前期：大多数人要么提前几天预订体验，要么是已经到了目的地之后才订。
  • 客单价方面他不给公司数字，但提示去 Viator 网站可看到：大多数活动定价约为「每个活动、每位旅客 40–50 英镑」。
  • 结合「多数旅客是两个大人带孩子的家庭」，他让采访方自行估算整单金额（即按人数×40–50 英镑推算 AOV）。
取消与改期政策
  • 对供应商「尽量很严格」，不让其主动取消活动；而旅客侧政策很宽松——允许在很短通知期内取消或改期，这被视为 Viator 产品的一个优势与强项。
  • 若供应商自行主动取消的预订每月超过某个阈值，相关产品会被判定为「低质量」，并在平台展示/排序上受到惩罚，会有实际后果。
  • 得益于对供应商的严格管理（确保其不自行取消），整体取消率「并不高」。
体验品类偏好
  • 毫无疑问的「赢家」是与景点相关的一切：埃菲尔铁塔、巴黎圣母院等景点周边/深入的导览游、团队游、徒步游。
  • 人们想到法国通常是奔着文化地标与美食而去：文化类活动排第一（参观巴黎圣母院、埃菲尔铁塔、卢浮宫、凡尔赛宫）。
  • 其后是泛泛在城里看建筑、感受文化的徒步游，再之后是美食游与葡萄酒；不止城市内，还有把人带到酒庄、看葡萄酒酿造的私人游。
  • 高端昂贵的体验往往是出城去酒庄/葡萄酒生产商的私人游，尤受有支付能力的旅客欢迎；他强调法国不只面向「成群结队、做便宜行程」的大众旅客，也能提供大量高端昂贵体验。
财务模型与法国市场增长趋势
  • 全球范围看是两位数增长；他估计大约在 10%–20%、也可能是 20%–30%（仅指 tourism activities 这块），并称 GetYourGuide 据他所知也是两位数增长。
  • 他认为法国也有类似的增速数字；并给出一个「简单计算方式」：那部分旅行大多是国际旅行，看飞往法国的航班与售出座位数即可——这些也在增长。
  • 结构性变化：更大比例的欧洲人在欧洲内部旅行、更多美国人前往欧洲；而更少亚洲人前往欧洲（很可能因全球各地冲突、机票变贵），全球旅游活动市场正在某种程度上转变。
  • 他「相当确定」（且声明为假设）：一旦东欧与中东等主要全球性扰动结束，会看到更大增长，因为他预计届时会有更多亚洲人来欧洲；市场未来几年仍有更大增长潜力，取决于地缘政治局势。
佣金费率与结构
  • 基础佣金率约为 20%；起始费率总在 20%–25% 之间，但之后可上可下，由具体负责该供应商的客户经理做出商业决定。
  • Viator 有「以佣金换曝光」的产品：供应商若给更高佣金即可让产品获得更多曝光/点击；也可能对大供应商给更低佣金却仍提供全部权益，因为想与其合作。
  • 因此「20%」这个标准数字其实说明不了什么——实际佣金可能在 5%–60% 之间，非常取决于具体供应商及双方关系。
  • 区分两类供应商：托管（managed）是大供应商，有专门客户经理深度对接、发生大量谈判（谈佣金、合作关系、开放哪些产品），其平均佣金「没人会告诉你」、供应商间差异极大。
  • 非托管（unmanaged）是太小、没有客户经理对接的供应商：自行进入平台、签标准合约、上传活动即上线、自我管理；其标准佣金约从 20%/21%/22% 起，想要更多曝光可上调。
获客结构与渠道（含 SEO 下滑与 AI 新渠道）
  • 对「CAC 与 LTV 的大致比例」问题他选择跳过；获客渠道则区分 Viator 本身与 TripAdvisor 集团：大量流量从 TripAdvisor 导入 Viator。
  • 其他渠道包括供合作伙伴接入的 API，以及搜索引擎优化（Google、Bing、Yahoo）。
  • （全球性趋势）来自搜索引擎的旅客占比正在下降，并非本行业独有：Google 更新改变了搜索运作方式，很多答案直接在搜索结果页给出，用户无需再点开网站——以前搜「Paris things to do」会点进链接，现在 Google 直接给答案，冲击了所有人的流量。
  • 应对策略 A：提升品牌认知度、提升已认识并习惯使用其 App/平台的旅客留存，确保旅客不流失。
  • 应对策略 B：与 AI 智能体/AI 搜索引擎合作，让其在组织答案时调用 Viator/TripAdvisor 的 API——这正成为新渠道；Viator 此前已公开宣布与 Anthropic 完成集成（他记得是一个 shopping action 购物功能），以确保 API 服务于这些大型 AI 公司。
竞争格局：GetYourGuide、Tiqets、Klook、Civitatis 及优劣势
  • 最主要、最大的竞争对手是 GetYourGuide，他认为没有谁能接近这个量级；Google 虽有 things to do 产品但服务的是不同场景、算不上真正竞争对手。
  • Klook 是更小的竞争且在亚洲更活跃，而 Viator 专注欧洲；市场上还有很多更小玩家。
  • Tiqets 此前未被视作大竞对，但最近被 Expedia 收购，使局面「变得有点意思」：Expedia 既是 Viator 依赖其 API 的合作伙伴，如今又有了自己内部的 Tiqets 供货。
  • 他对 Tiqets 收购案「有点担心」：Tiqets 专注博物馆门票、景点入场票——这恰是法国市场最关键的活动之一，Tiqets 拥有该库存且能直接供给 Expedia，对法国市场可能有影响（全球范围看则无碍）。
  • Civitatis 在他看过的统计/对比中都未显大、算不上很大玩家；他也指出从没见过专门针对法国市场的分布数据。
  • Viator 对 GetYourGuide 的优势在供给：仍拥有更多可售产品数量与已激活供应商，「供给的广度和深度」是其战略性优势。
  • 劣势：GetYourGuide 在欧洲市场捕获欧洲旅客方面做得非常好；分工大致是「Viator 把美国人带到欧洲，GetYourGuide 让欧洲人探索欧洲」。
  • 成因：Viator 相当依赖 TripAdvisor，而 TripAdvisor 在美国是更知名、更受欢迎的品牌，故历史上其旅客以美国为主；GetYourGuide 从无此优势、是欧洲起家，不得不在欧洲市场定位上大量投入并专门服务「欧洲人探索欧洲」，这正是其强项；他坦言「其实很想搞清楚 GetYourGuide 为什么做得更好」。
主要挑战：对美国客群的依赖
  • 最大挑战正是上文提到的——对美国旅客的依赖；他「真的很希望」平台上有更多欧洲旅客。
  • 结构性原因：欧洲是单一空间，欧洲人无论世界发生什么仍可在欧洲内部旅行，相对不受扰动影响；而长途国际旅行更易受通胀、冲突等扰动——如飞机燃油成本上涨使部分美国人放弃来欧洲/法国，去法国的美国人越少、Viator 在法国的收入就越少。
  • 缓解方向：吸引更多法国旅客本身（但其占比小于美国人），更要实现「旅行空间的多样性」、把重心从「去欧洲的美国人」转向欧洲人甚至其他客群。
  • 其余产品相关挑战（如法国市场折扣管理、创建折扣/优惠的能力、供应商与产品排序）他认为是「更小、可解决、只需排优先级」的问题；真正复杂、需更多投入的是改变旅客构成比例。
本地化运营（语言、客服、界面）
  • 托管供应商可用法语对接：设有「目的地经理」（destination managers，类似客户经理/商务经理），负责本地市场对接，对接法国的经理「几乎每次都是母语法语者」，故供应商可获本地化支持。
  • 非托管供应商通常直接联系客服团队，该团队默认讲英语；但他认为这如今不算大问题，因为有很容易翻译文本的能力——供应商用法语发邮件/文字也能翻译，回复再翻回法语。
  • 旅客侧平台已翻译成法语，旅客可用法语看到平台与全部内容。
  • 对「是否有专属法语客服」，他坦言不确定、其实不知道，称这是个有意思的问题、会去核实。
支付结算与「延迟付款」差异化
  • 支持各种银行卡：Visa、MasterCard，American Express 肯定支持（因与 American Express 合作）；对是否支持 Apple Pay/本地法国支付方式他不确定、需核实，后又提到 Apple 是支持的。
  • 法国本地的 carte bancaire（银行卡）支持；而 chèque vacances（由政府/雇主提供的度假支票）不支持。
  • 核心差异化是「延迟付款」（非法国特有、但很多旅客很喜欢）：可提前很久免费预订、Viator 一直保留该预订直到活动开始前约 24 小时才扣款，下单时甚至不在乎银行卡信息。
  • 他认为延迟付款比任何本地支付货币都更重要、运作得非常好、旅客正面反馈很多；但运营商没那么喜欢（更想立刻拿到钱）——因为 Viator 平台「旅客优先，而非供应商优先」。
长期趋势：供给数字化与动态定价
  • 本地团队薪资他不掌握，称取决于角色（总监/工程师/初级/资深）与地点（巴黎/马赛等），建议自行查证。
  • 增长机会与核心战略：让旅客基础多元化/全球化，带来更多来自美/英之外新地区的旅客；产品上不为法国专门构建，而是构建服务全球旅客的统一 marketplace（去法国、意大利或加州体验都应一致，仅极少数因法律差异如加州须显示销售税）。
  • 趋势一：供给数字化。法国/德国/英国的运营商正转向预订系统与渠道管理工具、依赖 API 与第三方平台分发体验；这对 Viator 也是好事——与其对接一万个法国运营商，不如对接一个服务一万运营商的单一 API，简化数据流。
  • 市场极碎片化：很多很酷的产品是「巴黎某一个人」独自打理的徒步游/一两人或一家人做的短途游，能产出很酷内容却完全没数字化、只用 Excel 等基础工具管理库存，更愿直接在 Viator/GetYourGuide 上创建并手动管理；如今这一状况正在改善。
  • 趋势二：动态定价。如何为产品定最优价是法/德运营商的难题；越来越多平台提供基于竞争对手活动、自身可售情况、甚至天气预报等因素动态生成价格的能力。
  • 他预计动态定价引擎很快会改变所有市场（不止法国），使该行业更像航空业——而当下多数价格仍是「有人拿着 Excel 表按每月手动创建/维护」的老派方式，正在改变。
对中国平台/trip.com 的建议
  • 若中国平台是 trip.com，他的建议是「与本地平台合作」，这比自己单干进入市场容易得多，因为这是个碎片化市场。
  • trip.com 擅长与高度数字化的行业（航空、酒店、租车）合作——那里已有大量 API；但 tourism activities 完全不同、API 不多，自己单干会有 50%–60% 内容得靠手动收集，工作量很大、从基础设施角度复杂——「何必冒那个险」，不如来找已有这些 API 的平台（GetYourGuide 或其他预订系统）。
  • 第二条建议：要非常清楚自己想服务哪类旅客——法国的「供给」与法国的「用户」是两个完全不同的故事，对应两套不同战略与行为模式。
  • 要分清是「进入法国市场以便在法国提供活动（拿供给）」还是「想获取法国客户（拿用户）」；他假设 trip.com 想要的是供给，那就专注于供给（法国旅客本身他不会列为优先）；若改为要法国客户，战略就转向用户获取而非供给获取。
成本结构：基础设施重于人力
  • 针对「员工成本占全球总预算多少」的追问，他认为「关联没那么大」，并再次引出托管/非托管之分来解释成本来源。
  • 为支持非托管供应商自助创建内容，平台必须维护让运营商创建价格与排期（schedules）的特定流程；这与航空/酒店不同——后者只需接上 API「消费」价格与排期，而 Viator「没有那种奢侈，必须自己把它造出来」。
  • 因此成本更多来自基础设施而非纯人力：但要支撑这套手动创建流程，仍需多个工程团队，外加产品经理、设计师以及部分客服团队成员。
  • 他强调：排期/价格并非由 Viator 员工维护，而是由供应商（运营商）自行维护，Viator 只需提供相应工具；对具体人力成本百分比他「不知道确切数据」。
