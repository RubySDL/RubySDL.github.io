C端用户旅游调研工作流

欧洲市场 · 用户访谈调研方案

一、基础问卷收集

目的：收集用户基本信息，供后续人工判断用户类型

执行方式：

  • 纸质问卷 → 组员手动录入 LimeSurvey
  • 线上链接 → 用户自主填写 LimeSurvey
产出：每位受访者一条 LimeSurvey 提交记录（含唯一提交 ID）

二、深度访谈执行

2.1 人工判断用户类型

根据基础问卷内容，由组员判断受访者属于以下哪类：

  • 折扣票用户
  • 海滨圈层用户
  • 露营圈层用户
  • 以上都不是（通用用户）

2.2 组合访谈大纲

用户类型 使用的访谈大纲
折扣票用户 通用访谈大纲 + 折扣票专项大纲
海滨圈层用户 通用访谈大纲 + 海滨圈层专项大纲
露营圈层用户 通用访谈大纲 + 露营圈层专项大纲
通用用户 仅通用访谈大纲

2.3 执行访谈并录音

  • 访谈语言：法语 / 英语 / 中文（视受访者情况）
  • 录音设备：iPhone / 录音笔
  • 文件命名：用户ID_日期_类型.m4a

三、访谈内容整理（AI 辅助）

3.1 录音转文字

1
语音识别Whisper
输入录音文件（.m4a / .wav），识别法/英/中多语种，输出原始语言文字稿

3.2 翻译 + 结构化整理

2
翻译为中文Claude
将非中文内容统一翻译为中文
3
按大纲结构化Claude
将访谈内容按大纲问题逐条匹配，提取每个问题对应的回答
录音文件 → Whisper 转写 → 原始文字稿 → Claude 翻译为中文 → 按大纲问题逐条匹配 → 结构化问答输出

四、最终产出

每位受访者整理为一份完整记录：

用户访谈结果（用户ID: xxx） ├─ 基础问卷部分 │ └─ LimeSurvey 提交 ID（或展开问卷各题填写内容） │ └─ 深度访谈部分 ├─ 通用访谈大纲 │ ├─ Q1: [问题] → A1: [回答] │ ├─ Q2: [问题] → A2: [回答] │ └─ ... └─ 专项访谈大纲（如适用） ├─ Q1: [问题] → A1: [回答] ├─ Q2: [问题] → A2: [回答] └─ ...

存储方式：回填至 LimeSurvey 或导出为独立文档

五、工具链总结

环节 工具 备注
基础问卷 LimeSurvey 收集 + 存储
访谈录音 iPhone / 录音笔 现场执行
语音转文字 OpenAI Whisper 多语种 ASR（法/英/中）
翻译 + 结构化 Claude 文本整理归类
结果存储 LimeSurvey / 文档 最终归档

六、待确认事项

  1. 四份访谈大纲的具体题目内容
  2. 最终产出的格式偏好（LimeSurvey 内管理 vs 独立文档/表格）
  3. 录音文件的存储位置和归档方式
